    What the Conviction Book shows

    When a token graduates from Meteora's Dynamic Bonding Curve, its price lives in a DAMM v2 pool. Anyone can rest DLMM limit orders on the same pair. The Conviction Book lists those resting orders against the DAMM v2 reference price, so you can see who is waiting to buy below the market or sell above it, how far away, and for how long.

    Statuses

    resting
    The reference price has not reached the order.
    crossed, in band
    The reference passed the order, but not by more than the estimated no-fill band (DAMM fee + DLMM fee). An arbitrageur would lose money filling it, so it may sit unfilled.
    arb-fillable
    The reference is past the order by more than the band. An atomic DAMM v2 → DLMM arbitrage could fill it.
    filled
    Fully filled. Proceeds stay in the order until the owner cancels it.

    Honest limits

    • Commitment is observed, not enforced. DLMM limit orders have no on-chain lock or expiry, and the owner can cancel at any time. "Open for" is time observed since creation.
    • The band is a lower bound. It uses base fees. The real DLMM fee has a variable part (a devnet test measured 45 bps against a 25 bps base), so the real band is wider.
    • The score is observational. Unfilled USD × days open (capped at 90) × proximity to the reference. It is not a reward, and nothing is paid out.
    • The DLMM pool does not track the reference by itself. Only arbitrage links the two pools, so the DLMM active price can drift far from DAMM v2.
    • This app cannot trade. It has no wallet connection and sends no transactions. The order preview is local arithmetic.
